# 边注（眉批／地脚批）

> 总纲见 [overview_zh_CN.md](overview_zh_CN.md)。本册只描述 `-hutu-note-placement: margin`。

## 1. 触发与落位

```css
.note {
  -hutu-note-placement: margin;
  -hutu-note-side: block-start;  /* 天头；block-end 为地脚 */
  -hutu-note-align: start;       /* start | center | end */
}
```

| `-hutu-note-side` | 位置 |
|---|---|
| `block-start` | 天头（竖排为版心上边距，横排为页上边距） |
| `block-end` | 地脚（竖排为版心下边距，横排为页下边距） |

- 注文元素必须是行内元素，且必须是锚点的后代。
- 一个注文元素生成**一组**边注行（竖排为列），整体放在边注区。
- 边注不改变正文的行高、行宽与位置。

## 2. 边注区

### 2.1 分页宿主

宿主提供分页时，边注区是该页对应侧的页边距区域。

### 2.2 连续滚动

宿主不提供分页时，边注区按以下顺序确定：

1. 从锚点沿该侧方向（天头向上、地脚向下）找**第一个**在对应侧 `padding` 非零的块容器：
   - 天头取 `padding-block-start`；
   - 地脚取 `padding-block-end`。
2. 该容器的这一侧 `padding` 区即边注区；版心是它的内容区。
3. 找不到这样的祖先时，取根元素（`html`）对应侧的 `padding` 区。
4. 仍为零时，可用空间为 0；按 §4.2 的“放不下”处理。

### 2.3 边注区的轴

边注区是一个矩形。它的尺寸按**注文自身**的书写模式解释：

- 竖排注文：inline 轴向下，block 轴向左。
- 横排注文：inline 轴向右，block 轴向下。

边注区在注文 inline 轴上的尺寸决定**一行（列）能排多长**；在 block 轴上的尺寸决定**能排多少行（列）**。

## 3. 定位与换行

### 3.1 书写模式

注文的 `writing-mode` 与 `direction` 继承锚点：

- 竖排正文 → 竖排眉批，一列向下排。
- 横排正文 → 横排眉批，一行向右排。

### 3.2 起始角

注文从边注区的 **inline-start／block-start 角**开始排（按注文自身的书写模式）：

- **竖排**：inline-start 是上缘，block-start 是右缘。天头从带的上缘、右缘起排；地脚从贴版心的上缘、右缘起排。
- **横排**：inline-start 是左缘，block-start 是上缘。天头从带的左缘、上缘起排；地脚从带的左缘、贴版心的上缘起排。

从起始角出发，沿 inline 轴排一行（列），再按 §3.4 换行。

### 3.3 对齐

- `-hutu-note-align` 把注文的**整体外接矩形**沿边注区的**长轴**（天头、地脚都是水平方向）相对锚点对齐：
  - `start`：注文外接矩形的长轴起点与锚点在长轴上的起点对齐；
  - `center`：注文外接矩形在锚点的长轴范围居中；
  - `end`：注文外接矩形的长轴终点与锚点在长轴上的终点对齐。
- 竖排时长轴是 block 轴，横排时长轴是 inline 轴。
- `start` 是初始值，也是传统眉批的常见位置。
- 对齐只移动注文整体，不改变每行（列）的长度与换行位置。
- 对齐使用边注区所在容器的坐标系；锚点的长轴位置按同一坐标系换算（扣除 padding 偏移）。

### 3.4 换行

1. 注文的行（列）沿 **inline 轴**排，长度受边注区在 inline 轴上的尺寸限制。
2. 一行（列）排满后，沿 **block 轴**换行（竖排向左换列，横排向下换行）。
3. 换行受边注区在 block 轴上的尺寸限制。
4. 若边注区在 inline 轴上的尺寸连一个字符都放不下，注文按溢出处理，沿 inline 轴延伸（竖排向下、横排向右），不受边注区限制。

### 3.5 竖排示例

正文 `vertical-rl`，天头 `padding-top: 24px`，眉批 `font-size: 8px; line-height: 1`：

- 每列最多 `24 / 8 = 3` 个字；
- 写满 3 字后向左换列；
- 列数受天头宽度限制。

## 4. 堆叠与避让

### 4.1 同一侧多条

1. 同一条边上的多条边注按锚点的 **DOM 顺序**依次排。
2. 后一条在前一条占用的 block 轴区间之后开始，**不得重叠**。
3. 多条边注之间默认无空隙；需要空隙时由作者用 `margin` 设置。
4. 不同侧的边注互不影响：天头与地脚各自独立堆叠。

### 4.2 放不下的顺序

一条边注在当前位置放不下时，按以下顺序尝试：

1. **声明侧**：先按 §3 排在 `-hutu-note-side` 指定的边。
2. **换边**：放不下则换到另一侧（`block-start` ↔ `block-end`）。
3. **换页**：若宿主提供分页，换到下一页的同侧边注区继续排。
4. **溢出**：以上都不行时，允许超出边注区；内容不裁切，由包含块的 `overflow` 决定可见性。

> 当前引擎未实现分页，第 3 步不会触发；连续滚动下最终落在第 4 步。

### 4.3 溢出方向

- 竖排：继续向左（block 轴），或按 §3.4 第 4 条向下（inline 轴）。
- 横排：继续向下（block 轴），或按 §3.4 第 4 条向右（inline 轴）。

## 5. 分片与分页

- 边注属于**锚点行所在的分片／页**。
- 锚点行被分片切开时，边注跟随锚点行的起始片段。
- 分页宿主下，一条边注可以跨页续排；续排时在下一页同侧边注区继续，阅读顺序不变。
- 连续滚动下不跨页，按 §4.2 溢出。

## 6. 字号与行高

- 未声明 `font-size` 时继承锚点。
- 建议显式写 `font-size: 0.5em`；传统眉批约为正文的一半。
- `line-height` 未声明时为 `normal`，按注文字体计算。
- 字号与行高都会影响 §2.3 的容量计算。

## 7. 与正文及其它特性的交互

- **正文布局**：边注不参与正文的行高、行宽、浮动避让与分栏计算。
- **选区与复制**：按 DOM 顺序参与，边注文字出现在锚点之后。
- **锚点隐藏**：锚点或注文元素被 `display:none`／移除时，边注消失。
- **装饰**：`margin`／`padding`／`border`／`background` 全部尊重，计入边注占用的区间。
- **多栏**：边注区取容器 padding，不取某一栏的内容区；作者应把留白写在页面容器上。
- **绝对定位**：注文元素上的 `position` 被忽略。

## 8. 验收点

1. 边注区矩形等于所选容器对应侧的 padding 区。
2. 注文整体沿边注区长轴按 `note-align` 相对锚点对齐。
3. 竖排眉批写满天头高度后向左换列；横排写满行宽后向下换行。
4. 同侧多条按 DOM 顺序堆叠且不重叠。
5. 放不下时按“声明侧 → 另一侧 → 换页 → 溢出”的顺序处理（无分页时跳过换页）。
6. 边注不改变正文任何行的位置。
7. 竖排、横排各一组用例。
8. 边注 `font-size` 与 `line-height` 改变时，容量计算随之改变。

## 9. 样例

```html
<style>
  .page {
    writing-mode: vertical-rl;
    padding: 24px 32px;       /* 天头/地脚 24px，左右 32px */
    font-size: 16px;
    line-height: 1.5;
  }
  .note {
    -hutu-note-placement: margin;
    -hutu-note-side: block-start;
    -hutu-note-align: start;
    font-size: 0.5em;
  }
</style>

<div class="page">
  <p>正文正文<span class="anchor">被注文字<span class="note">眉批：此處當作「長卿」。</span></span>正文正文</p>
</div>
```
