# 行内夹注（双行注）

> 总纲见 [overview_zh_CN.md](overview_zh_CN.md)。本册只描述 `-hutu-note-placement: inline`。

## 1. 触发与结构

```css
.note { -hutu-note-placement: inline; }
```

```html
<p>正文<span class="anchor">被注文字<span class="note">注文内容</span></span>正文</p>
```

- 注文元素必须是行内元素，且必须是锚点的后代。
- 一个注文元素生成**一个**夹注盒；夹注盒内部固定为两条子行。
- 注文盒排在锚点内、注文元素所在的 DOM 位置：即紧接在它前面的行内内容之后。

## 2. 几何

### 2.1 记号

- `n`：注文按 `white-space` 处理后的排版字符数（按字素簇计，组合符号随基字）。
- `L`：锚点所在行盒的**已用行高**（used `line-height`）。
- `f`：注文的已用字号。

### 2.2 字号

```
f = min(注文声明的 font-size, L / 2)
```

- 未声明 `font-size` 时取继承值，再按上式截断。
- `f` 的截断是**硬约束**：它保证 `2f ≤ L`，即两子行总高不超过行盒。
- 建议作者显式写 `font-size: 0.5em`；不写时常见结果是 `0.75em`（当 `L = 1.5em`），比传统夹注大。

### 2.3 尺寸

| 量 | 值 |
|---|---|
| 每格 inline 尺寸 | `f` |
| 注文盒 inline 推进（单片段） | `ceil(n / 2) × f` + 注文元素的 margin／padding／border |
| 每子行 block 尺寸 | `f` |
| 注文盒 block 尺寸 | `2f` + 注文元素的 margin／padding／border |

- 跨行时，总推进是各片段之和 `Σ ceil(n_i / 2) × f`。每个片段独立向上取整，所以当多个片段都是奇数字时，总推进会比单片段公式多出半格（每多一个奇数字片段 +`f/2`）。
- 两子行沿 block 轴并排：第一子行靠 **block-start**（竖排为右列，横排为上行），第二子行靠 **block-end**（竖排为左列，横排为下行）。
- 默认装饰下，注文盒的 block 中心与锚点行盒的 block 中心重合。
- 默认无装饰时，`2f ≤ L` 保证注文盒落在行盒内；它可以占用行距空白，但**不得**改变行盒高度。作者添加 `padding`／`border` 后可能超出，后果由作者承担。

### 2.4 字符分配

- 前 `ceil(n / 2)` 个字符进第一子行，其余 `floor(n / 2)` 个进第二子行。
- 注文为奇数字时，第一子行多一字，第二子行末格留空半格。
- 两子行的 inline 起点对齐；第二子行不足的格在 inline-end 留空。

### 2.5 前后空隙

- 默认**无空隙**：注文盒紧接前一行内内容，后一行内内容紧接注文盒。
- 作者在注文元素上声明的 `margin`／`padding`／`border` 按普通盒模型加入推进；此时空隙由作者负责。

## 3. 断行

1. 夹注**可以**在格边界断行；断点处两子行同时结束，下一片段从新行开始。
2. 每个片段**独立**分配字符：片段内前一半进第一子行，后一半进第二子行；奇数字时第一子行多一字。这样片段内的阅读顺序始终是“第一子行 → 第二子行”。
3. 行末剩余 inline 空间不足一格（`f` + 装饰）时，该格整体移到下一行；**不得**把一格拆到两行。
4. 夹注不限长，可以跨任意多行／多列。
5. 片段之间的阅读顺序为：片段 1 第一子行 → 片段 1 第二子行 → 片段 2 第一子行 → ……，与 DOM 顺序一致。

### 3.1 示例

正文 `font-size: 16px`、`line-height: 24px`，注文 `font-size: 8px`：

- `f = min(8, 12) = 8px`，`2f = 16px ≤ 24px`。
- 注文 7 字：`ceil(7/2) = 4` 格，inline 推进 `32px`；第一子行 4 字，第二子行 3 字 + 半格空。
- 若当前行只剩 3 格空间：片段 1 取 6 字（3 + 3），片段 2 取 1 字（1 + 0）。

## 4. 边界情况

| 情况 | 行为 |
|---|---|
| `n = 0` | 不生成注文盒，等价于 `none` |
| `n = 1` | 占 1 格；第一子行 1 字，第二子行空 |
| 奇数字 | 第一子行多一字 |
| 连续空格 | 按 `white-space` 的折叠规则处理后再计 `n` |
| 注文内有 `<br>` | 暂按普通行内换行：结束当前片段并另起一行（见总纲 §8） |
| 注文内有 ruby | 允许；注音排在同一子行内，不得改变 `f` 与 `2f` |
| 注文出现在 `rt` 内 | `-hutu-note-placement` 不生效，按 `none` 处理 |
| 注文内有嵌套注文 | 内层不生效，按普通行内内容排 |
| RTL 文本 | 字符顺序按 `direction`；子行顺序仍按 block-start／end（见总纲 §8） |

## 5. 与其它特性的交互

- **行高**：夹注不改变锚点行高；它只在行盒内占位与绘制。
- **`text-emphasis`**：注文内的着重号按子行排版；是否绘制、画在哪一侧，见总纲 §8。
- **`text-decoration`**：按片段绘制；默认 `box-decoration-break: slice`。
- **`text-spacing-trim` / `hanging-punctuation`**：不作用于夹注内部（暂定）。
- **`text-combine-upright`**：不作用于夹注内部；夹注本身已是半字宽。
- **浮动与绝对定位**：注文元素上的 `float`／`position` 被忽略。

## 6. 验收点

以下量必须可被布局探针断言：

1. 单片段时，注文盒 inline 推进 = `ceil(n/2) × f`（默认装饰下）；跨行时按片段累加。
2. 默认装饰下，注文盒 block 尺寸 = `2f`，且 `2f ≤ L`。
3. 第一子行字符数 = `ceil(n/2)`，第二子行 = `floor(n/2)`。
4. 断行位置只落在格边界；每片段独立对半分。
5. 锚点行行高与无注文时完全相同。
6. `n = 1`、奇数字、空注文三种边界。
7. 跨 2 行、跨 3 行以上时，片段顺序与 DOM 顺序一致。
8. 作者设置 `margin`／`padding` 时，推进按盒模型增加。

## 7. 样例

```html
<style>
  .page { writing-mode: vertical-rl; font-size: 16px; line-height: 1.5; }
  .note { -hutu-note-placement: inline; font-size: 0.5em; }
</style>
<p class="page">司馬相如者，蜀郡成都人也<span class="anchor">，字長卿<span class="note">案：長卿，相如之字也。</span></span>。</p>
```
