# 行间注

> 总纲见 [overview_zh_CN.md](overview_zh_CN.md)。本册只描述 `-hutu-note-placement: interline`。

## 1. 触发与结构

```css
.note {
  -hutu-note-placement: interline;
  -hutu-note-fit: push;      /* 或 squeeze；初始值 push */
  -hutu-note-align: start;   /* start | center | end */
}
```

- 注文元素必须处于行内格式化上下文中。
- 一个注文元素生成**一个注文块**；注文块沿 inline 轴通栏，内部像普通文本一样换行。
- `-hutu-note-fit` 决定注文块占不占块向空间：
  - `push`：独立成块，撑开后续内容。
  - `squeeze`：塞进注文所在行与其后一行之间的行距空隙，不推移后续内容。

## 2. 通栏与对齐

### 2.1 通栏宽度

注文块**每一行**的 inline 尺寸等于**注文所在行的可用 inline 尺寸**：

- 无浮动时：注文所在块容器（多栏时为所在栏）的内容宽／高。
- 有浮动时：注文所在行避让浮动后的行盒 inline 尺寸，注文块不额外避让，因此不会盖住浮动。
- 竖排：内容高；横排：内容宽。

### 2.2 对齐

`-hutu-note-align` 控制注文块**每一行**的文字在这条通栏行内的对齐：

| 值 | 行为 |
|---|---|
| `start` | 文字从该行的 inline-start 排起 |
| `center` | 文字在该行内居中 |
| `end` | 文字在该行的 inline-end 结束 |

- 多行注文逐行对齐，行为与 `text-align` 相同。
- 注文块每一行的尺寸不随 `-hutu-note-align` 改变。

## 3. push 模式

### 3.1 位置

- 注文块插在**注文所在行盒之后**，属于同一个块容器。
- 注文所在行之后的正文继续排在注文块之后；段落被切开，但仍是同一段落（缩进、对齐、标点悬挂按段落规则继续）。
- 注文块不改变段落内其它行的断行位置；它只增加块向高度。

### 3.2 尺寸

| 量 | 值 |
|---|---|
| 每行 inline 尺寸 | 注文所在行的可用 inline 尺寸（通栏） |
| block 尺寸 | 注文块各行 `line-height` 之和 + 注文的 margin／padding／border |
| 后续内容位移 | 等于注文块的 block 尺寸 |

- 注文块的 block 起点紧接注文所在行的 block-end。
- 注文块与后续行之间不额外加空隙；需要空隙时由作者用 `margin` 设置。

### 3.3 同一行多个注文

同一行内有多个行间注时，按注文位置在行内的 inline 顺序，依次在该行之后插入注文块；先出现的注文先排。

### 3.4 段落最后一行

注文位于块的最后一行时，注文块仍插在该行之后，并撑开块的高度；块之后的兄弟内容随之下移。

## 4. squeeze 模式

### 4.1 位置

- 注文块放入注文所在行与其**后一行**之间的行间空隙。
- 注文块的 block-start 与注文所在行内容区的 block-end 重合；超出可用空隙的部分压住下一行。
- 注文块不移动后续行；后续行的位置与无注文时相同。
- 注文所在行是块的最后一行时，注文块仍放在该行之后，可溢出到块外。

### 4.2 可用空隙

```
G = max(0, L − C)
```

- `L`：注文所在行的已用行高。
- `C`：注文所在行的内容区高度（字体内容区，即 ascent + descent，不含 leading）。
- `G` 即行距（leading）的空白部分。

判定：

- 注文块的 block 尺寸 `l ≤ G`：放入空隙，正常排版。
- `l > G`：**溢出**。注文块仍从空隙起点排，超出部分压住下一行；不推移后续行，也不自动改为 `push`。
- 溢出部分由包含块的 `overflow` 决定是否可见；本规范不额外裁切。

> `squeeze` 只适合短注。长注会大量溢出；作者应改用 `push`。

### 4.3 同一行多个注文

同一行有多个 squeeze 注文时，按注文位置在行内的 inline 顺序在同一空隙内依次堆叠：

- 第 1 块从空隙起点排；
- 第 2 块从第 1 块的 block-end 排；
- 总高超过 `G` 时，从超出的那块起溢出。

### 4.4 与 push 的取舍

`squeeze` **不得**自动退回 `push`。作者要保证行距足够，否则就是溢出——这是规范明确选择的取舍。

## 5. 字号与行高

- 注文字号由注文元素声明；未声明时按 CSS 继承规则取得。
- 建议注文字号 ≤ 正文 `font-size`，但规范不设硬上限（见总纲 §8）。
- 注文 `line-height` 未声明时为 `normal`，按注文字体计算。
- 注文块的高度按实际行数累加，不按“一条行”固定。

## 6. 分片与分页

- 注文块跟随注文所在行所属的分片（fragment）／页。
- 注文块本身不拆分；若注文块高于一个分片，按分片规则裁切或整体下移（具体规则待定）。
- 分页宿主下，注文所在行与注文块必须留在同一页；放不下时整组移到下一页。

## 7. 与其它特性的交互

- **浮动**：注文块的每行宽度取注文所在行的可用宽度，浮动不会被盖住。
- **多栏**：通栏宽度取注文所在栏的内容宽／高。
- **绝对定位**：注文元素上的 `position` 被忽略。
- **装饰**：`margin`／`padding`／`border`／`background` 全部尊重，计入注文块的 block 尺寸。

## 8. 验收点

> 类型标记：**探针** = 数值几何断言；**Reftest** = 与参考页做带文字抗锯齿容差的截图比较；**探针 + Reftest** = 两者均必须。

1. **探针**：`push` 后续内容位移 = 注文块 block 尺寸。
2. **探针**：`push` 注文块每行 inline 尺寸 = 注文所在行可用 inline 尺寸。
3. **探针 + Reftest**：`squeeze` 后续行位置与无注文时完全一致。
4. **探针 + Reftest**：`squeeze` 的 `l ≤ G` 时，注文块完整落在空隙内。
5. **探针 + Reftest**：`squeeze` 的 `l > G` 时按溢出处理，不改为 push。
6. **探针 + Reftest**：同一行多个注文时，`push` 按 inline 顺序插块；`squeeze` 按顺序堆叠。
7. **探针 + Reftest**：段中注文之后，段落后半段继续排布，缩进与对齐不变。
8. **探针 + Reftest**：`note-align` 的三种取值只改变文字位置，不改变行尺寸。
9. **探针 + Reftest**：多栏与竖排下通栏尺寸取所在栏，不取整页。
10. **探针 + Reftest**：长注在 `push` 下正常折成多行，block 尺寸按行数累加。

## 9. 样例

```html
<style>
  p { font-size: 16px; line-height: 1.5; }
  .note { -hutu-note-placement: interline; -hutu-note-fit: push; font-size: 0.75em; }
  .squeeze { -hutu-note-fit: squeeze; }
</style>

<p>正文前半被注文字<span class="note">这是一条独立成块的
行间注，长到一行放不下时会在注文块内部换行。</span>正文后半。</p>

<p>正文前半被注文字<span class="note squeeze">这是一条挤在行距里的短注。</span>正文后半。</p>
```
